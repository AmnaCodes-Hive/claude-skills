Lecture Notes Structuring Skill a blog post for me 
When to Use This Skill
User shares lecture notes or class slides

User asks to organize, clean, or summarize notes

User mentions exams, revision, or study preparation

Procedure
Identify core topics: Detect main headings and themes

Structure content: Organize into logical sections and subpoints

Extract key concepts: Highlight definitions and formulas

Add clarity: Include short explanations or examples

Summarize: Create a concise revision-friendly summary

Output Format
Topic Overview: 2–3 sentence overview of the lecture
Structured Notes: Headings with bullet points
Key Definitions / Formulas: Clearly listed
Examples: Short, exam-relevant examples
Revision Summary: 5–7 bullets for quick review

Quality Criteria
Structure: Clear hierarchy (topic → subtopic → detail)

Language: Simple, student-friendly

Length: Optimized for revision, not transcription

Focus: Exam-relevant, avoids unnecessary detail

Example
Input: “These are my OS lecture notes on process scheduling”

Output:

Topic Overview: This lecture explains how operating systems manage CPU time among multiple processes.

Structured Notes:

Process Scheduling

Definition

Goals (CPU utilization, fairness)

Types (FCFS, SJF, Round Robin)

Key Definitions:

Scheduling: Method of deciding which process runs next

Revision Summary:

Scheduling improves CPU efficiency

Different algorithms suit different workloads
