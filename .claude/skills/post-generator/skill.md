Learning Post Generator Skill
When to Use This Skill
User shares what they learned today

User wants to post consistently on LinkedIn

User asks for a professional learning post

Procedure
Identify learning event: What was learned or built

Extract insight: One meaningful takeaway

Write reflection: What changed in understanding

Keep tone authentic: Simple, not promotional

Close with growth mindset: Learning-forward ending

Output Format
LinkedIn Post: 5–7 lines
Key Insight: One sentence takeaway

Quality Criteria
First-person perspective

Clear learning outcome

No buzzwords

Beginner-friendly tone
