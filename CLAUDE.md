# CLAUDE.md

## Project Overview
This is a Claude Skills project containing custom skills designed to enhance Claude's capabilities in specific areas. The project currently includes several specialized skills that extend Claude's functionality for particular use cases.

## Skills Included

### Error Explainer
- **Purpose**: Translate programming or API error messages into clear explanations with actionable fixes
- **Trigger**: When users share error messages or are stuck debugging
- **Functionality**:
  - Classifies errors by type and severity
  - Explains what the error means in plain language
  - Identifies potential root causes
  - Suggests specific, actionable fixes
  - Provides prevention tips for future avoidance

### Lecture Notes Structurer
- **Purpose**: Transform raw lecture notes or slides into structured, exam-ready study material
- **Trigger**: When users share lecture notes or ask to organize educational content
- **Functionality**:
  - Identifies core topics and themes
  - Structures content in a logical hierarchy
  - Extracts key concepts and definitions
  - Adds clarity and context where needed
  - Creates summaries and review materials

### Post Generator
- **Purpose**: Convert daily learning or progress notes into professional LinkedIn posts
- **Trigger**: When users share learning updates or want to create professional posts
- **Functionality**:
  - Identifies significant learning events or achievements
  - Extracts key insights and takeaways
  - Writes thoughtful reflections
  - Maintains an authentic, professional tone
  - Formats content appropriately for the target platform

## How to Use These Skills
1. Simply mention the type of task you want to accomplish
2. Provide the relevant input (error message, lecture notes, learning updates, etc.)
3. The appropriate skill will automatically engage and provide enhanced assistance

## Technical Architecture
- Built as extensions to Claude's core capabilities
- Designed to recognize specific patterns in user requests
- Integrated seamlessly into conversation flow
- Maintains Claude's helpful and ethical guidelines
