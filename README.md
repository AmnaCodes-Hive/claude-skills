# 🧠claude-skills – README

This repository contains **three focused agentic AI skills** built to solve real, repeatable problems faced by students and beginner developers.

Each skill is:

* Small and single-purpose
* Triggered by clear user intent
* Designed to reduce cognitive load
* Easy to reuse by others with similar workflows

These skills follow an **agentic design approach**: clear inputs → structured reasoning → predictable outputs.

---

## 📦 Skills Included

### 1. Learning Post Generator

**Name:** `learning-post-generator`
**Version:** 1.0.0

**Purpose**
Turns daily learning or progress notes into a professional, beginner-friendly LinkedIn post.

**Problem It Solves**
Learning happens daily, but converting it into consistent, high-quality posts takes unnecessary mental effort.

**When to Use**

* User shares what they learned today
* User wants to post consistently on LinkedIn
* User asks for a professional learning post

**Core Outcome**
A short, authentic LinkedIn post with one clear learning insight.

**Output**

* LinkedIn Post (5–7 lines)
* One-sentence Key Insight

**Quality Standards**

* First-person perspective
* Clear learning outcome
* No buzzwords or promotional tone
* Beginner-friendly language

---

### 2. Lecture Notes Structurer

**Name:** `lecture-notes-structurer`
**Version:** 1.0.0

**Purpose**
Transforms raw lecture notes or slides into structured, exam-ready study material.

**Problem It Solves**
Students often have unorganized notes that become difficult to revise before exams.

**When to Use**

* User shares lecture notes or class slides
* User asks to organize or summarize notes
* User mentions exams, revision, or study preparation

**Core Outcome**
Clean, structured notes optimized for fast revision.

**Output**

* Topic Overview (2–3 sentences)
* Structured Notes (headings + bullet points)
* Key Definitions / Formulas
* Short, exam-relevant examples
* Revision Summary (5–7 bullets)

**Quality Standards**

* Clear hierarchy (topic → subtopic → detail)
* Simple, student-friendly language
* Focused on exam relevance
* No unnecessary transcription

---

### 3. Error Explainer

**Name:** `error-explainer`
**Version:** 1.0.0

**Purpose**
Explains programming or API error messages in simple language and provides actionable fixes.

**Problem It Solves**
Error messages are often confusing and slow down debugging for beginners.

**When to Use**

* User pastes an error message
* User is stuck debugging
* User mentions API or runtime errors

**Core Outcome**
Clear understanding of the error with step-by-step resolution guidance.

**Output**

* Error Meaning (simple explanation)
* Likely Causes (bullet list)
* Step-by-Step Fix
* One Prevention Tip

**Quality Standards**

* No guessing beyond evidence
* Fixes must be actionable
* Explanations written for beginners
* Avoids overwhelming the user

## 🧩 Design Principles

All skills in this repository follow these rules:

* **Single clear outcome** per skill
* **Narrow scope** (no feature creep)
* **Predictable structure** and output
* **Reusable** by people with similar needs
* **Measurable value** (time saved, clarity gained)
